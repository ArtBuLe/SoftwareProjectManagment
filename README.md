**Задание 1. Создание WBS**

Этап 1: Проектирование
- Анализ требований к системе
- Проектирование структуры базы данных
- Создание макетов пользовательского интерфейса

Этап 2: Backend разработка
- Реализация API регистрации и авторизации
- Реализация API создания, редактирования и смены статусов задач
- Реализация API поиска и назначения исполнителей

Этап 3: Frontend разработка
- Создание форм входа и регистрации
- Разработка интерфейса просмотра и создания задач
- Реализация интерфейса управления задачами (исполнители, статусы)

Этап 4: Тестирование и внедрение
- Функциональное тестирование всех модулей
- Исправление выявленных ошибок
- Развертывание приложения на сервере

**Задание 2. Определение контрольных точек**

1. Утверждены технические требования и макеты интерфейса.
2. Готова и проверена структура базы данных.
3. Основная функциональность реализована и интегрирована (бэкенд и фронтенд связаны).
4. Тестирование завершено, приложение готово к запуску.

**Задание 3. Определение зависимостей**

- Проектирование базы данных начинается только после завершения анализа требований.
- Разработка API зависит от готовности и утверждения структуры базы данных.
- Разработка интерфейса зависит от готовности макетов и наличия API для интеграции данных.
- Функциональное тестирование начинается только после полной интеграции фронтенда и бэкенда.
- Развертывание приложения возможно только после успешного завершения тестирования и исправления критических ошибок.
