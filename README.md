Практическая работа №2. Разработка устава программного проекта

Восстановление концепции проекта

Название проекта: Разработка консольной игры «Тетрис» на языке C#.
Описание проблемы: Отсутствие простого, легковесного консольного приложения с классической механикой «Тетриса», которое можно использовать для коротких перерывов в учёбе и которое служит наглядным примером реализации игрового цикла и логики на C#.
Целевая аудитория: Сам разработчик и одногруппники.
Цель: Создать за 1–2 недели работающее консольное приложение на C#, реализующее базовые механики «Тетриса».
Ожидаемый результат: Скомпилированный исполняемый файл (.exe) и исходный код с реализованным игровым циклом, управлением, подсчётом очков и экраном завершения игры.
Участники: Булышев А.А. (выполняет все роли: руководитель, аналитик, разработчик, тестировщик).
Ограничения: Срок 1–2 недели, бюджет 0 руб., платформа Windows (консоль).

Определение границ проекта

Входит в проект:
- Отрисовка игрового поля (10x20) символами в консоли.
- Реализация 7 классических тетромино и их поворота.
- Обработка коллизий (столкновение со стенами, дном и другими фигурами).
- Удаление заполненных линий и сдвиг поля.
- Подсчёт очков и условие завершения игры (Game Over).
- Сборка в автономный исполняемый файл (.exe) для Windows.

Не входит в проект:
- Графический пользовательский интерфейс (GUI) или использование игровых движков (Unity, Godot).
- Звуковое сопровождение или музыка.
- Сохранение таблицы рекордов в файл или базу данных.
- Сетевой мультиплеер.
- Поддержка операционных систем, отличных от Windows.


Определение критериев успеха

1. Приложение успешно запускается в стандартной консоли Windows без ошибок и не требует прав администратора.
2. Игрок может управлять фигурой (двигать влево/вправо, вращать), и она корректно останавливается при столкновении с границами поля или другими застывшими фигурами.
3. При полном заполнении горизонтальной линии она удаляется, фигуры выше сдвигаются вниз, а значение счётчика очков увеличивается.


Оформление устава (Project Charter)

1. Название проекта: Разработка консольной игры «Тетрис» на языке C#.

2. Обоснование проекта: Существует потребность в легковесном приложении для короткого отдыха, а также в учебном примере, демонстрирующем навыки работы с игровой логикой, массивами и консольным вводом-выводом в C#.

3. Описание проблемы: Отсутствие простой консольной реализации «Тетриса», которую можно быстро запустить на учебном ПК без установки дополнительного ПО, и которая служила бы понятным примером архитектуры игры для изучения одногруппниками.

4. Цель по SMART: Разработать за 1–2 недели консольное приложение на C# с реализацией 7 фигур, механикой падения, поворота, очистки линий и подсчёта очков, результатом которого является готовый .exe файл.

5. Заказчик: Преподаватель / Учебное заведение (как оценщик компетенций), а также сам разработчик (как инициатор).

6. Целевая аудитория: Студенты-одногруппники и сам разработчик.

7. Заинтересованные стороны: Булышев А.А. (разработчик), одногруппники (пользователи), преподаватель (оценщик), системный администратор (обеспечение среды).

8. Руководитель и участники: Булышев А.А. (единолично выполняет роли руководителя, аналитика, разработчика и тестировщика).

9. Границы проекта:
Входит: консольная отрисовка, логика 7 фигур, коллизии, очки, Game Over, сборка .exe.
Не входит: графика (GUI), звук, сохранение рекордов, мультиплеер, кроссплатформенность.

10. Предполагаемые сроки: 1–2 недели (14 дней).

11. Необходимые ресурсы: Персональный компьютер с установленной средой разработки (Visual Studio / VS Code), компилятор .NET, время разработчика. Бюджет: 0 руб.

12. Основные риски:
Технический: мерцание консоли при перерисовке кадров или задержки ввода.
Организационный: нехватка времени из-за совмещения всех ролей одним человеком.
Архитектурный: плохая структура кода на старте, затрудняющая добавление механики очистки линий на поздних этапах.

13. Критерии успеха: Корректный запуск без прав админа, работающее управление и коллизии, корректное удаление линий и начисление очков.
